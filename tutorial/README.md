# DS-Projekt 2026 tutorial

This tutorial follows one example from an empty repository to a first answer. The question arrived as a single sentence: "Is cycling in Zurich growing?"

Each chapter shows three things together: how to think about the step, how to build it, and how to do it with Claude Code.

This folder holds the tutorial text. Everything else in this repository was built by the steps the chapters describe, so every result a chapter links to is the real one.

## Chapters

| Chapter | What you have at the end |

## How to use the prompts

Prompts and commands stand in grey boxes. Move the mouse over a box and a copy button appears at its top right.

The prompts are broken into short lines so that you can read them without scrolling sideways. Paste them as they are. Claude Code does not mind the line breaks.

The prompts belong to the example. For your own project, keep their structure and replace the details: your question, your data, your fixture and your expected values.
